# اپ انبارگردانی (Android native)

## این پروژه چیست؟
یک اپ اندروید بومی (Kotlin) با:
- اسکن بارکد از طریق دوربین (CameraX + ML Kit — کاملاً روی گوشی و بدون اینترنت اجرا می‌شود)
- وارد کردن فایل CSV اولیه (بارکد، نام کالا، قیمت)
- ثبت تعداد شمارش‌شده برای هر قلم
- خروجی CSV نهایی
- **چاپ برچسب بارکد** برای کالاهای انتخاب‌شده، روی چاپگر شبکه‌ای زبرا (ZPL)

## چرا CSV به‌جای XLSX واقعی؟
کتابخانه‌های خواندن/نوشتن فایل باینری Excel (مثل Apache POI) روی اندروید به کلاس‌های جاوا که در اندروید وجود ندارند وابسته‌اند و باعث خطاهای build غیرقابل پیش‌بینی می‌شوند. CSV یک فرمت متنی ساده است که:
- با API‌های داخلی خود اندروید (بدون کتابخانه اضافه) خوانده و نوشته می‌شود → build مطمئن‌تر
- در اکسل، گوگل‌شیت و هر نرم‌افزار صفحه‌گسترده دیگر مستقیماً باز می‌شود (کافیست هنگام ذخیره در اکسل گزینهٔ «CSV» رو انتخاب کنی)

## بخش ۱ — ساخت APK با گیت‌هاب (بدون کامپیوتر/Android Studio)

1. یک حساب رایگان در github.com بساز
2. یک ریپازیتوری جدید و **Public** بساز
3. تمام فایل‌های این پروژه را با همان ساختار پوشه‌ای آپلود کن (پوشهٔ `server-bridge` نیازی نیست آپلود شود — فقط برای اجرا روی سرور است، نه بخشی از اپ اندروید)
4. به تب **Actions** برو — workflow «Build APK» خودکار اجرا می‌شود (چند دقیقه طول می‌کشد)
5. وقتی ✅ سبز شد، روی آن اجرا کلیک کن، پایین صفحه بخش **Artifacts** را باز کن و `inventory-app-debug` را دانلود کن (داخلش `app-debug.apk` است)

## بخش ۲ — نصب APK روی گوشی
1. فایل `app-debug.apk` را روی گوشی منتقل کن
2. رویش بزن؛ اگر پیام «نصب از منابع ناشناس مسدود است» آمد، از تنظیمات اجازهٔ نصب را برای همان اپ (مرورگر/فایل‌منیجر) فعال کن
3. نصب را تأیید کن

## بخش ۳ — استفادهٔ روزمره از اپ
1. دکمهٔ «📄 ساخت نمونه فایل CSV» را بزن تا فرمت فایل را ببینی
2. فایل CSV واقعی خودت را (با همان ستون‌های بارکد/نام کالا/قیمت) با «وارد کردن CSV» بارگذاری کن
3. با «شروع اسکن» دوربین را باز کن و بارکدها را اسکن کن، تعداد را وارد و «افزودن به شمارش» را بزن
4. در پایان با «خروجی CSV» فایل نتیجه را ذخیره کن

## بخش ۴ — راه‌اندازی چاپ برچسب بارکد (چاپگر زبرا)
چون پرینتر زبرا با USB به یک سرور/کامپیوتر وصل و در شبکه Share شده، اندروید نمی‌تواند مستقیم با آن صحبت کند. یک اسکریپت پل (`server-bridge/print_bridge.py`) لازم است که روی همان سرور اجرا شود:

1. فایل `print_bridge.py` را روی همان کامپیوتر ببر
2. با Notepad بازش کن و خط `PRINTER_SHARE_NAME = "Zebra"` را با نام دقیق اشتراک پرینترت جایگزین کن (Control Panel → Devices and Printers → راست‌کلیک روی پرینتر → Properties → Sharing → Share name)
3. اگر پایتون نصب نیست، از python.org نصبش کن
4. با دستور `python print_bridge.py` در Command Prompt اجرا کن — این پنجره باید باز بماند تا چاپ کار کند
5. با دستور `ipconfig` آدرس IPv4 همان کامپیوتر را پیدا کن

سپس در اپ اندروید:
1. از صفحهٔ اصلی روی «🖨 چاپ بارکد کالاها» بزن
2. آی‌پی همان سرور و پورت `9100` را وارد و «ذخیره» را بزن
3. کالاهای موردنظر را تیک بزن، تعداد برچسب هر کدام را وارد کن
4. «چاپ برچسب‌های انتخاب‌شده» را بزن

**نکته:** اگر اسم کالاها فارسی باشد، ممکن است روی برچسب درست چاپ نشود چون فونت پیش‌فرض چاپگرهای زبرا از یونیکد/فارسی پشتیبانی کامل ندارد؛ خود بارکد و اعداد بدون مشکل چاپ می‌شوند. برای پشتیبانی کامل فارسی روی برچسب، نیاز به نصب فونت یونیکد روی حافظهٔ چاپگر است (با Zebra Setup Utilities) — در صورت نیاز بعداً می‌توان اضافه کرد.

## نکات مهم
- این یک build نوع «debug» است (برای تست شخصی مناسب است)
- اگر ترجیح می‌دهی از کامپیوتر با Android Studio استفاده کنی، کافیست پوشهٔ اصلی پروژه (بدون `server-bridge`) را در Android Studio باز کنی و روی Run بزنی
